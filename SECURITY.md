# Security policy

Report vulnerabilities privately through GitHub: **Security tab, then "Report a vulnerability"** at <https://github.com/muxalot/muxalot/security/advisories/new>. Please don't open a public issue.

Most sensitive areas: signature verification and replay protection, pairing codes, path confinement for file transfer, and anything that could expose a terminal to an unauthenticated client.

Only the latest release is supported. You can expect an acknowledgement within a few days.
